# Screenshot Studio

Local generator for the Kestrel Wallet App Store screenshots: iPhone 6.9″, iPad 13″ and iPhone Duo,
every store locale, two variants (A "Night", C "Big type").

```sh
cd fastlane/screenshot-studio
node server.mjs          # → http://localhost:4547   (PORT=… to change)
```

No npm install. Export uses Playwright's cached headless Chromium (`~/Library/Caches/ms-playwright`);
set `CHROME=/path/to/chrome` if it is missing (`npx playwright install chromium-headless-shell`).
Fonts come from macOS: New York (headlines) and SF Pro (body), served from `/System/Library/Fonts`.

## Files

| Path | What |
|---|---|
| `project.json` | devices, slide order, background + eyebrow colour per slide, gradient `backgrounds`, variants |
| `copy/<locale>.json` | text per slide key: `eyebrow`, `title`, `body` |
| `assets/shots/<locale>/<device>/<slide>.png` | raw app screenshots; a locale without its own falls back to `en-US` |
| `render.mjs` | the slide layout (one HTML page per slide at its exact pixel size) |
| `scripts/collect.sh` | copies an export into the folders the fastlane upload lanes read |
| `out/<variant>/{ios,duo}/<locale>/` | exports (git-ignored) |

Slides, in order: `home, send, receive, activity, coin, transfer, security, widget, welcome`.

## Raw screenshots

Capture with the DEBUG `-demo` launch flag (sample wallet, no network), signed build (see AGENTS.md).

| Device folder | Simulator | Raw PNG |
|---|---|---|
| `iphone` | iPhone 18 Pro Max | 1320 × 2868 (measured) |
| `ipad` | iPad Pro 13-inch (M5), portrait | 2064 × 2752 |
| `duo` | iPhone Duo, unfolded (inner display; capture by hand, see below) | 2007 × 2853 |

The device frame follows the real size of each PNG, so a simulator that produces slightly different
pixels still fits without cropping; the studio flags unexpected sizes in its summary bar. A shot in the
wrong orientation keeps the configured frame and gets cropped (top-aligned).

## In the studio

- Click a slide to edit its text for the selected locale (⌘↵ saves) or pick its background gradient.
- Drag a PNG onto any slide to set that slide's screenshot for the selected locale.
- **Compare A/C** shows both variants under each other for product page optimisation.
- **Export…**: variants × devices × locales, JPG or PNG. Use JPG: App Store Connect rejects images
  with an alpha channel.

Without raw shots every slide renders a striped "Screenshot missing" placeholder, so layout and copy can
be checked before capture.

## Export → fastlane

```sh
node server.mjs export --devices iphone,ipad,duo --locales en-US          # variant A, JPG
node server.mjs export --variants C --devices iphone --locales all       # other combinations
scripts/collect.sh                 # A → ../screenshots/<locale>/ (iphone + ipad) and ../screenshots-duo/<locale>/
scripts/collect.sh C en-US         # a different variant / only some locales
```

Then, from the repo root, `fastlane ios upload_screenshots` (iPhone + iPad) and
`fastlane ios upload_duo_screenshots` (Duo). Both need `ASC_APP_VERSION`; see `../README.md`.

## Adding a locale

Create `../metadata/<locale>/` (the studio's locale list is those folder names) and write
`copy/<locale>.json` by hand. Translations are written by a person, never generated by a script or an
API. Copy fallbacks: en-GB/AU/CA → en-US, fr-CA → fr-FR, es-MX → es-ES, pt-PT → pt-BR, everything
else → en-US (flagged "EN text" in the studio). RTL locales (`ar-SA`, `he`, `ur-PK`) and CJK line
breaking are handled in `render.mjs`; long headlines shrink until they fit above the device.
